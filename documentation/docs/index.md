# 2P-Kt

[tuProlog](https://www.cs.nmsu.edu/ALP/2013/10/tuprolog-making-prolog-ubiquitous/) (2P) is a multi-paradigm logic
programming framework originally written in Java. **2P-Kt** is a Kotlin-based, multi-platform (JVM, JS, and
beyond) reboot of 2P: an open ecosystem for Symbolic Artificial Intelligence, built as a set of incrementally
inter-dependent modules for symbolic manipulation and reasoning.

that matches what you're trying to do.
